# News Chat (Ollama) — API (npm)

A tiny API that will answer questions about financial news from a provided JSON file, summarized via **Ollama** (wired in later commits). This first commit only sets up the server and a health endpoint.

## Prerequisites
- Node.js 18+
- npm (bundled with Node)

## Setup
```bash
npm install
npm run dev
# then open http://localhost:5173/api/health
